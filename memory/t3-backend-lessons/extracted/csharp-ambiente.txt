C# e .NET: Qual a relação?
C# é a linguagem de programação moderna, expressiva e orientada a objetos
criada pela Microsoft. .NET é o ecossistema que compila, interpreta e executa
esse código.


          Pense assim: C# é o idioma que você fala, e .NET é o país com toda a
       infraestrutura necessária para que essa comunicação aconteça.

A importância da CLI
A Command Line Interface do .NET oferece poder total no terminal,
independente de qualquer IDE ou interface gráfica.

•   dotnet new — cria um novo projeto a partir de um template
•   dotnet build — compila o projeto
•   dotnet run — executa a aplicação
•   dotnet publish — prepara para produção

Seleção de Workloads: Web
O que é um Workload?

Um workload é um conjunto agrupado de ferramentas, SDKs e templates
voltados a um tipo específico de desenvolvimento. Ao invés de instalar
componente por componente, você seleciona o pacote adequado.
Para desenvolvimento web com C#, marque:



          Desenvolvimento ASP.NET e Web — inclui automaticamente o .NET
       SDK, templates de projeto web, Kestrel e ferramentas de publicação.

Validando o Ambiente
Antes de escrever qualquer linha de código, confirme que o SDK foi
instalado corretamente e que o ambiente está pronto.
O comando dotnet
Abra o Prompt de Comando ou o PowerShell e execute os comandos abaixo
para verificar a instalação:


  dotnet --version
  dotnet --list-sdks
  dotnet --list-runtimes


Se os SDKs instalados aparecerem na listagem, o ambiente está configurado
corretamente e pronto para uso.

Criando a Solution
No Visual Studio, uma Solution é o contêiner de mais alto nível que organiza um
ou vários projetos relacionados em uma única estrutura gerenciável.

•   Permite agrupar projetos interdependentes
•   Facilita o build e debug de múltiplos projetos
•   Organiza a estrutura de pastas no disco



       Boas práticas: use nomes em PascalCase sem espaços para Solutions e
       Projetos.
Criando um Console App
                Passo a passo no Visual Studio

                1. Clique em Criar novo projeto
                2. Busque por Console App
                3. Selecione a versão sem ".NET Framework" no nome
                4. Defina o nome do projeto (ex: HelloWorld)
                5. Confirme a versão do .NET mais recente




                          Atenção: evite o template .NET Framework — ele é legado e
                      limitado ao Windows.
O arquivo Program.cs

O ponto de entrada da aplicação

O Program.cs é onde a execução começa. Com o .NET 6+, a estrutura foi
simplificada com Top-Level Statements:


  // Hello, World! em C# moderno
  Console.WriteLine("Hello, World!");


O compilador entende que este é o ponto de entrada e executa o código
sequencialmente, linha por linha, do topo ao fim do arquivo.
