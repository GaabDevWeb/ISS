(1.3) Sobre o SQLite
O SQLite não é diretamente comparável aos mecanismos de banco de dados SQL cliente/servidor, como MySQL, Oracle, PostgreSQL ou SQL Server, pois o SQLite está tentando resolver um problema diferente.

Os mecanismos de banco de dados SQL cliente/servidor se esforçam para implementar um repositório compartilhado de dados corporativos. Eles enfatizam escalabilidade, simultaneidade, centralização e controle. O SQLite se esforça para fornecer armazenamento de dados local para aplicativos e dispositivos individuais. SQLite enfatiza economia, eficiência, confiabilidade, independência e simplicidade.

SQLite não compete com bancos de dados cliente/servidor.

(1.4) Sobre o DuckDB
O DuckDB é um Sistema de Gerenciamento de Banco de Dados (SGBD) de código aberto, leve, rápido e fácil de usar, projetado para armazenar e gerenciar dados em ambientes de ciência de dados, análise de dados e machine learning. Ele é conhecido por sua:
- Leveza e portabilidade
- Rápido desempenho
- Sintaxe SQL simples e fácil de usar
- Compatibilidade com formatos de dados comuns (CSV, JSON, Parquet, etc.)
- Integração com ferramentas de ciência de dados populares (Python, R, etc.) 
Obs.: No Deepnote é usado o DuckDB.

(1.7) Usar o SQLite no Windows (por linha de comando) 
https://www.sqlite.org/download.html
            . Baixar o arquivo sqlite-tools-win-x64-3510200.zip. 

            . Criar uma nova pasta de sua escolha (por exemplo: c:\SQLite).

            . Mover para a nova pasta criada o arquivo sqlite-tools-win-x64-3510200.zip.

            . Descompactar o arquivo sqlite-tools-win-x64-3510200.zip.

            . Abrir uma janela DOS:
            -- Procurar onde está o arquivo sqlite3.exe
            dir c:\sqlite3.exe /s
            Obs.: Caso você saiba onde está o arquivo citado, ir para o próximo passo.
        
            -- Ir para o diretório (pasta) citada no comando anterior
            cd c:\SQLite

            -- Iniciar o SQlite e usar o database teste.db
            sqlite3 teste.db

            -- Help
            .help 

            -- Mostrar os databases existentes
            .databases

            -- Listar as tabelas existentes
            .tables

           -- Criar tabela clientes
           create table clientes
           (cod_cliente int,
           nome_cliente varchar(10),
           celular_cliente varchar(11));

            -- Listar as tabelas existentes
            .tables
	
            -- Verificar o conteúdo da tabela
            select * from clientes;

            -- Inserir registros	
            insert into clientes values (1, 'Maria', '9000');
            insert into clientes values (2, 'João', '8000');

            -- Verificar o conteúdo da tabela
            select * from clientes;

            -- Verificar o modo padrão do SQLite
            .mode

            -- Alterar o modo padrão do SQLite
            .mode table

            -- Verificar o conteúdo da tabela
            select * from clientes;

            -- Para sair da linha de comando do SQLite
            .quit

            Obs.: Com isso você desativa o database.
