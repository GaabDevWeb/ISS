-- Excluindo dados desnecessários
. Ter certeza que você precisa apagar os dados. 
. E caso o dado seja apagado e posteriormente aja necessidade de desfazer o que foi apagado, dependerá do SGBD (com seus recursos e versões) para saber se isso será possível. 
. Têm vezes que o dado é apagado apenas logicamente (no caso uma coluna é alterada e assim na visão do sistema parece que o dado foi apagado). Não ocorrendo um apagar físico.

Obs.: Não existe o comando truncate para o SQLite. 
	Então para apagar os dados em si (DML):
		DELETE FROM estabelecimentos_backup2;
		SELECT count(*) FROM estabelecimentos_backup2; 
	Para apagar a estrutura da tabela (DDL): 
		DROP TABLE estabelecimentos_backup2;
		SELECT count(*) FROM estabelecimentos_backup2;
