	. Entendendo os dados
-- A mesma empresa é citada no mesmo endereço mais de uma vez? 
SELECT empresa,
       rua,
       cidade,
       estado,
       count(*) AS conta_endereco
FROM estabelecimentos
GROUP BY empresa, rua, cidade, estado
HAVING count(*) > 1
ORDER BY empresa, rua, cidade, estado;

-- Quantas empresas existem em cada estado? 
SELECT estado,
       count(*) AS conta_estado
FROM estabelecimentos
GROUP BY estado
ORDER BY estado;

-- Mostrar as colunas quando o estado for NULL
SELECT id_estabelecimento,
       empresa,
       cidade,
       estado,
       cep
FROM estabelecimentos
WHERE estado IS NULL;

SELECT char(39)||estado||char(39),

ORDER BY estado;

Obs.: Buscar o nome da empresa iniciada por 'Armour'. Existem 4 formas diferentes de escrever essa empresa. 

SELECT empresa,
       count(*) AS conta_empresa
FROM estabelecimentos
WHERE empresa like '%Armour%'
GROUP BY empresa
ORDER BY empresa ASC;

-- Quantos registros apresentam 5 caracteres na coluna cep? 
SELECT length(cep),
       count(*) AS conta_comprimento
FROM estabelecimentos
GROUP BY length(cep)
ORDER BY length(cep) ASC;

SELECT length(cep), cep
FROM estabelecimentos
ORDER BY cep ASC;

-- Confirmar se determinados registros apresentam menos do que 5 caracteres para a coluna cep
SELECT estado,
       count(*) AS conta_estado
FROM estabelecimentos
WHERE length(cep) < 5
GROUP BY estado
ORDER BY estado ASC;
Obs.: Os estados citados teriam no início do texto um número 0 ou dois números 0s. Na conversão foram tirados os zeros. 

SELECT estado, cep, length(cep) 
FROM estabelecimentos
WHERE length(cep) < 5
ORDER BY estado ASC, cep ASC;

	. Corrigir os seguintes problemas: 
(1) Valores sem indicar o estado (para a coluna estado) para 3 registros; 
(2) Ortografia inconsistente do nome de pelo menos uma empresa (Armour);
(3) CEPs imprecisos devido à conversão de arquivos (no início do campo possuía 1 ou 2 números 0 e devido a conversão para número esses zeros foram desconsiderados).
